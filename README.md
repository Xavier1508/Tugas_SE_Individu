# GitHub Python Tutorial

## Deskripsi Singkat
Proyek ini menunjukkan cara menggunakan Git dan GitHub untuk mengelola proyek Python sederhana.

## Cara Menjalankan
1. Buka terminal
2. Jalankan: `python hello.py`
3. Masukkan nama Anda, dan lihat hasil sapaan
